FOOTER BAĞLANTISI GÜNCELLEMESİ

1. ZIP dosyasını bilgisayarınızda ayıklayın.
2. İçindeki src ve scripts klasörlerini ve build.py ile wrangler.jsonc dosyalarını mevcut GitHub deposunun köküne yükleyin. ZIP dosyasının kendisini yüklemeyin.
3. Mevcut dosyaları aynı yollar üzerinde güncelleyin; yeni bir üst klasör oluşturmayın.
4. Commit sonrası Cloudflare build ve deploy işlemlerinin başarıyla tamamlanmasını bekleyin.

Beklenen dosyalar:
/src/site/index.html
/scripts/generate.py
/build.py
/wrangler.jsonc

Cloudflare:
Root directory: / (depo kökü)
Build command: python build.py
Workers deploy command: npx wrangler deploy
Pages build output directory: dist

Paket hazır dist çıktısını da içerir. Git bağlantılı build için src ve scripts kaynakları esas alınır.

Kontrol: Ana sayfa ve rehber footer'ında Plaka Sorgulama bağlantısı https://plakarehberi.com/ adresine yönlenmelidir.
